Under the hood

Real engines, not a wrapper.

The same libraries that power desktop tooling, compiled to run in the browser. The whole application is a single HTML file you can download, read and self-host.

PDF engine
PDF-Lib for document structure, Mozilla's pdf.js for rendering and page recovery. PDF encryption implements the PDF 2.0 standard (128-bit RC4) natively in JavaScript, so protected files open in Acrobat, Chrome, Edge, Safari and Preview.
Office formats
PptxGenJS for PowerPoint, docx for Word, SheetJS for spreadsheets. Text-based conversion draws with the built-in WinAnsi fonts, which cover Latin-1 — non-Latin scripts are reported rather than silently dropped.
Imaging & OCR
Ghostscript (WASM) for genuine PDF recompression, the browser's own canvas for image work, and Tesseract.js for OCR across seven languages.
Encryption
A hand-written MD5 and RC4 implementation following the PDF 2.0 specification. No crypto dependency, no key material leaving the page.
